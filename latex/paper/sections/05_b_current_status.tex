\subsection{Current Prototype Status}
At the current stage, the prototype implements a complete local benchmarking pipeline including a Python workload generator, a configurable sequencer, a simplified transfer-centric executor, and a Hardhat-based L1 settlement stub. Components such as EIP-4844 blob submission and proof generation are currently modeled or parameterized via a mock prover. Therefore, the evaluation is framed as controlled configuration sweeps measuring relative trade-offs rather than production mainnet benchmarking.
