\section{Cost Amortization}
\label{sec:cost_results}
Stage 1 and Stage 5 analyses confirmed the theoretical cost amortization curve. Larger batch sizes significantly reduced the amortized Layer-1 gas cost per transaction.

In Stage 1 (using a Mock Verifier with ~29,000 fixed gas overhead):
\begin{itemize}
    \item \textbf{Batch Size 25}: True Weighted Gas/Tx was 20,549 gas.
    \item \textbf{Batch Size 100}: True Weighted Gas/Tx was 19,681 gas.
    \item \textbf{Batch Size 500}: True Weighted Gas/Tx was 19,459 gas.
\end{itemize}

While the gas savings appear small (~5\%) due to the mock verifier's low overhead, Stage 5 experiments utilizing the real \texttt{risc0} proof backend demonstrated the massive impact of the real prover fixed cost. The proving wall-clock time was modeled via linear regression as $T(N) = 75\text{s} + 5.7\text{s} \times N$. 

This high fixed setup cost (75 seconds to compile/load the guest ELF and wrap the STARK proof) makes small batches extremely inefficient. At batch size 50, the amortized proving cost was 7.5 seconds per transaction, whereas at batch size 246, it dropped to 6.0 seconds per transaction. A proposed dual-axis plot demonstrating Batch Size vs. Queue Latency \& Gas Cost clearly illustrates the diminishing returns of increasing batch size against the penalty of queue wait times.
