\section{Calldata vs Blob Efficiency}
\label{sec:data_availability_results}
\begin{itemize}
    \item \textbf{Calldata Footprint:} When using calldata, the Submitter passes the transaction payload directly in the L1 transaction. The marginal L1 cost per transaction observed in Stage 5 was approximately 19,300 gas per transaction, driven by the cost of copying transaction bytes as calldata (16 gas per byte).
    \item \textbf{Blob Efficiency:} Switching the DA mode to EIP-4844 blobs (as designed in the Submitter architecture) minimizes the L1 execution footprint. Because the EVM only verifies a cryptographic commitment to the blob (rather than storing the data permanently), the on-chain footprint is reduced to the fixed submission cost plus the separate, cheaper "blob gas" fee.
\end{itemize}
