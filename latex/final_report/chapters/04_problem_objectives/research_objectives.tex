\section{Research Objectives}
\label{sec:research_objectives}

To systematically answer the research questions, the project defines the following specific objectives emphasizing modularity and reproducibility:

\begin{itemize}
    \item \textbf{RO1:} Design and implement a modular research-grade ZK-rollup benchmarking framework with separable sequencer, executor, prover, submitter, smart contract, and data availability components.
    \item \textbf{RO2:} Develop a reproducible experimental pipeline that supports controlled configuration sweeps over batching policies, sequencing policies, prover modes, and data availability modes under synthetic workloads.
    \item \textbf{RO3:} Empirically evaluate ZK-rollup performance trade-offs by measuring throughput, latency, finalization time, proving overhead, data availability footprint, and per-transaction cost across selected configurations.
\end{itemize}
