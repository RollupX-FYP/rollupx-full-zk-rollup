\chapter*{Abstract}
This report outlines my individual contributions to the modular ZK-rollup benchmarking framework project. Throughout the development lifecycle, my primary focus was on architecting the L1 interaction layer and engineering the rigorous benchmarking infrastructure necessary to evaluate our prototype. I led the development of the Submitter service, applying Domain-Driven Design (DDD) to implement robust, mock-testable Data Availability (DA) strategies, including EIP-4844 Blobs, Calldata, and Off-chain DA. Concurrently, I developed the complementary L1 smart contracts for batch settlement and proof verification. To validate our research questions, I constructed a fully automated, reproducible benchmarking suite featuring a Poisson process workload generator and complex matrix execution scripts. Furthermore, I built the Python-based data analysis pipeline to aggregate distributed metrics and generate statistical plots. Evidence for these claims was rigorously collected using a forensic Git history analysis across all repository branches, inspecting diffs and code histories rather than relying solely on high-level commit messages.
