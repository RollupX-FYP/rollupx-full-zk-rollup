Key Research Discoveries — Anomalies Found & Fixed
⚠️ Anomaly 1: Nonce Reordering Vulnerability
Global fee-based scheduling placed nonce N+1 before nonce N for the same sender, causing 100% rejection for multi-tx senders. Gas/tx spiked to ~112k (all empty batches).
✓ Fixed: Two-tier nonce-aware scheduler — group by sender, sort each sender's queue by nonce ascending, then apply global policy on queue heads only.
⚠️ Anomaly 2: Hysteresis Threshold Trap
Adaptive batching flaw: if N_small ≥ L_t, no valid mempool depth satisfies both the size trigger AND the low-load condition simultaneously. Adaptive policies converged to fixed batching under all loads.
✓ Fixed: Enforce N_small < L_t in config validation. Patched system shows correct three-tier load-adaptive behavior.
⚠️ Anomaly 3: Aggregation Anomalies
Simple arithmetic mean of batch metrics caused 16% inflation in reported queue latency (8,212ms reported vs. 7,061ms true). Empty trailing batches inflated L1 gas averages.
✓ Fixed: Volume-weighted averages for all latency and cost metrics. Trailing empty batches excluded from cost computations.
5-Stage Benchmarking Plan
Stage 1
Fixed Batching Characterization
Varied batch size (25–1000 tx) and timeout (0.5s–200s) at 10 TPS. Validated: W_q ≈ ½·min(T_timeout, B/λ) within ±3% empirically.
Stage 2
Adaptive Batching Under Varying Load
Three-tier load-responsive batch sizing. Discovered and fixed the hysteresis trap. Patched system shows correct low/medium/high load switching.
Stage 3
Scheduling Policy Evaluation
Compared all 5 policies. TimeBoost achieved best JFI (0.773). Discovered nonce reordering bug in global-sort policies; fixed with two-tier scheduler.
Stage 4
Data Availability Mode Analysis
Calldata (20,700 gas/tx) vs. EIP-4844 Blob (4,600 gas/tx, 78% saving) vs. Offchain (3,600 gas/tx, 84% saving). Blobs require N≥1000 for economies of scale.
Stage 5
ZK Proof Generation Scaling (RISC0)
Step-function scaling: ~70–80s fixed overhead + ~5.7s/tx. Final Groth16 proof is always 256 bytes regardless of batch size. BN254 pairing precompile verification on L1.
